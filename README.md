# Street-Fighter-6-Stereoscopic-3D-Mod










**Installation Guide**

1. Extract the contents of the downloaded zip file.
2. Copy the `dinput8.dll` file into the folder containing the game's main executable (`game.exe`).
3. Open the settings menu and select **Stereo 3D** from the dropdown list.
4. Toggle the option to **Enable 3D**.
5. Choose the **Stereo output** setting that matches your specific display type.
